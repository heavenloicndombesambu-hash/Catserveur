🏆 Classement

📖 Les 13 rôles

🟢 Innocents

Équipier : termine les missions.

Détective : enquête sur les joueurs.

Médecin : protège un joueur.

Ingénieur : utilise les conduits.

Juge : possède un double vote utilisable une fois.

Shérif : peut éliminer un joueur qu'il soupçonne. S'il se trompe, il perd son pouvoir.

🔴 Méchants

Tueur classique : élimine et sabote.

Sniper : élimine à distance.

Ninja : peut devenir invisible.

Métamorphe : peut prendre l'apparence d'un autre joueur.

Tous les méchants ont un délai entre leurs éliminations.

🟣 Neutres

Pélican : doit éliminer tous les innocents. Il possède 2 vies.

Mentaliste : disponible uniquement au-dessus de 6 participants ; doit découvrir les rôles de 2 joueurs.

Bouffon : gagne s'il est éliminé par un vote.
